# pi-observer 原型

**这是设计产物，不作为开发产品。** 它只定义视觉规范、信息结构与交互约定；产品界面按 Next.js + React 组件重写，只沿用这里的设计约定与 token 值，不复制这里的代码。

纯静态 HTML/CSS/JS，没有构建步骤，没有网络请求，也没有任何写操作。

打开方式：

```bash
open prototype/index.html          # 或者直接用浏览器打开这个文件
```

## 文件

| 文件 | 页面 | 说明 |
|:--|:--|:--|
| `index.html` | **单页应用** | 左栏项目 / 会话，右栏会话头 + 筛选 + 时间线；行详情用弹窗；亮 / 暗主题 |
| `request.html` | 请求详情 | 弹窗内容的独立参考页：payload、响应头、token、关联 |
| `tool.html` | 工具调用详情 | 弹窗内容的独立参考页：参数、结果、部分结果、失败态 |
| `jsonl.html` | 会话文件条目 | 弹窗「原始 JSON」的参考：读取规则、条目类型、原始行 |
| `probe.html` | 探针状态 | 连接、队列、事件订阅清单、只读约束、保留与清理 |
| `style-guide.html` | 设计规范 | 色板、字号、组件、颜色语义、页面清单 |
| `styles.css` | 设计系统 | 所有 token（暗色 + 亮色两套）与组件样式 |
| `app.js` | 交互 | 会话切换、筛选、Turn 折叠、分页、弹窗、主题 |

`request.html` / `tool.html` / `jsonl.html` 在产品里**不再是独立路由**：同样的内容放在时间线每一行的「详情」弹窗里。保留这三个文件是为了单独检查排版与信息密度。

## 页面结构（`index.html`）

```
┌────────────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · 应用 / 探针 / 规范 · 探针状态 · 亮暗切换              │
├──────────────────┬─────────────────────────────────────────────────┤
│ 左栏 298px       │ 会话头：cwd / id / 状态 / 对账 / 条目 / token   │
│  搜索            ├─────────────────────────────────────────────────┤
│  /项目           │ 筛选：消息 会话 运行 工具 模型 探针 · 思考 · 分支│
│    · 会话        ├─────────────────────────────────────────────────┤
│    · 会话        │ 时间线（独立滚动）                              │
│  /项目           │  加载更早的 20 个 Turn                          │
│    · 会话        │  ▸ Turn 33  摘要 · 时间 · 工具数 · token · 成本 │
│                  │  ▾ Turn 34  进行中（自动展开）                  │
│  只读提示        │      用户 / 助手 / 工具结果 / 事件行            │
├──────────────────┴─────────────────────────────────────────────────┤
│ 状态栏：探针 · 最近推送 · 队列 · 丢弃 · 真相源                   │
└────────────────────────────────────────────────────────────────────┘
```

要点：

- **没有消息树**，也没有 `/sessions/[id]` 这样的详情页。所有内容都在右侧时间线里。
- 时间线以**会话文件条目**为主（用户、助手、工具结果、系统条目），**钩子事件**只补文件里没有的信息（请求 / 响应、工具起止、运行状态、模型切换、探针健康）。
- Turn 默认折叠；进行中的 Turn 自动展开；默认最近 20 个，点「加载更早」再取 20 个。
- 每行右侧的 `⋯` 打开详情弹窗：元信息、正文 / 参数 / 结果、原始 JSON、关联事件。
- **不显示流式正文**：生成中的 Turn 只显示「等待助手写入会话文件…」。
- 不在当前分支上的条目默认隐藏，用「其它分支」开关显示。

## 点击路径

```
index.html
  ├─ 左栏会话 ──▶ 右栏切换（地址同步为 #s=<会话 id>）
  ├─ 任意条目行 ⋯ ──▶ 详情弹窗（内容排版参考 request.html / tool.html / jsonl.html）
  ├─ 会话头「会话文件」──▶ jsonl.html
  └─ 顶栏 ──▶ probe.html / style-guide.html
```

## 主题

- 默认**暗色**；顶栏右侧按钮或快捷键 `D` 切换。
- 选择写入 `localStorage["pi-observer-theme"]`，刷新后保持；首屏之前用内联脚本应用，避免闪一下。
- 亮色是「中性灰底 + 墨色文字」，不是把暗色简单反相。
- 所有颜色都走 `styles.css` 顶部的变量：`:root` 是暗色，`html[data-theme="light"]` 覆盖亮色。页面里没有写死的颜色。

## 设计语言

- 全部等宽字体，数字 `tabular-nums` 右对齐
- 只用 1px 发丝边框和背景层次区分区块，不用投影、不用渐变
- 微标签用 9–10px 大写 + `.1em` 字距承担层级
- 颜色只表达语义：绿=成功/进行中、琥珀=警告/空闲/成本、红=失败、蓝=链接/provider、紫=助手条目/思考、粉=工具、青=用户条目/会话
- 圆角三档：4px 控件、6px 面板、10px 弹窗
- 改配色、字号、行高：只改 `styles.css` 顶部的 tokens，两套主题同步生效

## 原型里的交互约定（`app.js`）

| 属性 | 用法 |
|:--|:--|
| `data-sess` + `data-view` | 左栏会话行；点击后切换到对应的 `data-view` 面板 |
| `data-sess` 上的 `data-cwd/id/state/recon/.../c-*` | 切换会话时填充右栏会话头与筛选计数 |
| `data-cat-chip="msg\|session\|run\|tool\|model\|probe"` | 时间线分类开关；`data-cat` 可写多个值（空格分隔） |
| `data-think-chip` / `data-branch-chip` | 思考过程 / 不在当前分支的条目 |
| `data-load-earlier` + `data-earlier` | 「加载更早」：显示隐藏的一页并保持滚动位置 |
| `data-expand-all` | 展开 / 收起当前会话的全部 Turn |
| `data-detail="d-tool"` | 打开 `<template id="d-tool">` 里的详情弹窗；`Esc` 或点遮罩关闭 |
| `data-theme-toggle` | 亮 / 暗主题切换 |
| `data-sb-search` | 左栏会话搜索（摘要、项目、id） |
| `data-tabgroup` + `data-tab` / `data-panel` | 标签页（弹窗与参考页） |
| `data-copy="#选择器"` | 复制目标节点的文本 |

快捷键：`D` 主题、`T` 思考、`B` 其它分支、`E` 展开 / 收起全部、`/` 搜索、`Esc` 关闭弹窗。

原型为了能直接双击打开，用 `#s=<id>` 模拟产品的 `?session=<id>`；产品里用查询参数切换，不整页刷新。

## 刻意不包含

- 真实数据。所有数字与会话都是写死的示例，方便对照样式。
- 任何写操作。没有删除、隐藏、重命名、重跑、停止、发送。
- 后端与网络。原型只表达界面与信息结构。
- 流式正文与逐字动画。
- 产品代码。这里的 HTML/JS 不会被搬进产品；产品侧按组件重写（见 `docs/tech-stack.md` §6）。

## 加页面时

复制一份最接近的页面，改 `data-panel` 的名称与顶栏的 `active` 类；样式一律复用 `styles.css` 里的类，不要写新的行内颜色。新增颜色时，`:root` 与 `html[data-theme="light"]` 两处都要加。
